### T2 — Reconcile dapp's 489% (algebra)

Inputs (from W0 evidence packet + 2026-04-30 dapp probe, all measured):

```
e_liq_per_epoch_pendle = 309.96
long_pendle_per_day    = 33.67     (current epoch)
side_split             = 0.760     (= 33.67 / 44.29)
margin_per_yu_usd      = 18.30     (W1)
collateral_usd         = 100
pendle_price_usd       = 1.35
incentivized_range     = [0.52, 1.17]   (current epoch)
orderbook_in_range_sum = ~165 YU   (raw, from order_book_raw parquet)
dapp_long_apr_badge    = 489%
```

Solve for the `(q_me, sigma_others)` pair that the dapp is implicitly using:
```
489% × $100 / 365 / $1.35 = X PENDLE/day        (= 0.992 PENDLE/day)
share = X / long_pendle_per_day                  (= 0.0294)
share = q_me / (sigma + q_me)
=> sigma = q_me × (1 - share) / share            (= q_me × 33.04)
```

Plot or tabulate `(q_me, sigma)` on this curve. Compare against:
- `q_me = 4.92, sigma = 165` → share = 0.0289 → APR = 480% (within 5% of 489%) ✓
- `q_me = 4.92, sigma = 75`  → share = 0.0615 → APR = 1020% (matches my earlier W5 back-calc, not the dapp)

Output: wiki page `[[dapp-apr-reconciliation-2026-04-30]]` (Status: Current) with the reconciliation, including a one-paragraph note retracting CONTEXT.md's "effective pool ≈ 75 YU" assumption if T1 confirms `share = q_me / (sigma + q_me)` and the reconciliation lands within tolerance.

### T3 — Compute the band (script)

`scripts/derive_expected_verdict_band.py`:
- CLI flags: `--market`, `--side`, `--config` (path to strategy YAML), `--epoch` (prior|current|both), `--sigma-source` (parquet|dapp), `--out-json`.
- Reads `margin_per_yu_usd`, `q_max_safety_margin`, `collateral_usd`, `pendle_price_usd` from the config.
- Reads `e_liq_per_epoch_pendle`, `long_side_split`, `short_side_split` from `state/state.sqlite` operator rows (effective_at_utc filtered, latest per epoch).
- For sigma_others:
  - `--sigma-source parquet`: reads `data/parquet/order_book_raw` at the start, mid, and end of the replay window's chain_ts range, computes in-CLO-range cumulative size at each.
  - `--sigma-source dapp`: takes the empirical effective-pool value from the W0 evidence packet (~75 YU long).
- Outputs `(low, mid, high)` USD-APR-fraction values + the inputs used, formula citation, and timestamp.

Determinism: same inputs → same outputs to 1e-9 relative tolerance. No randomness, no time.time() (use chain_ts from data).

Smoke test (in `scripts/test_derive_expected_verdict_band.py` or as a doctest): pin a fixture and assert the output JSON matches a stored golden.
