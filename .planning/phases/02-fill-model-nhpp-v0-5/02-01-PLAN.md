```python
class FillModelConfig(StrictBase):
    """Knobs for the NHPP fill model (FILL-01..06). Reflection-surfaced in RUN_MANIFEST."""
    window_days: int = Field(14, ge=7, le=30)
    bin_duration_s: float = Field(60.0, ge=30.0, le=300.0)
    refit_cadence_s: float = Field(900.0, ge=60.0, le=3600.0)
    covariate_whitelist: list[str] = Field(default_factory=lambda: list(DEFAULT_COVARIATE_WHITELIST))
    queue_tracker_bias_mode: Literal["pessimistic", "optimistic", "realized"] = "pessimistic"
    gof_ks_pval_threshold: float = Field(0.0, ge=0.0, le=0.5)
    gof_lr_ratio_threshold: float | None = None  # bootstrap-calibrated at first fit
    fit_warn_staleness_s: float = Field(1800.0, ge=600.0, le=7200.0)
    fit_max_staleness_s: float = Field(3600.0, ge=0.0, le=28800.0)
    bracket_width_warn_multiplier: float = Field(0.5, ge=0.1, le=2.0)
    min_events_per_param_ratio: int = Field(10, ge=5, le=50)

    @field_validator("covariate_whitelist")
    @classmethod
    def _whitelist_subset(cls, v: list[str]) -> list[str]:
        bad = [x for x in v if x not in ALLOWED_COVARIATES]
        if bad:
            raise ValueError(f"covariate_whitelist contains non-allowed entries: {bad}")
        return v
```

# Fill model library decision — tick vs statsmodels

**Status:** Current — v0.5 regime
**Filed:** 2026-04-24
**Author:** planner (Phase 2)
**Supersedes:** amends [[python-stack-v05]] (role of `tick` changed, NOT removed)

## Decision

The critical-path NHPP-with-covariates fit for v0.5 uses
`statsmodels.GLM(family=Poisson(link=log), exposure=bin_duration_s)`, NOT `tick`.

## Why

- `tick` 0.8.0.1 ships `SimuInhomogeneousPoisson` (simulator) and Hawkes learners
  (`HawkesExpKern` etc.) but does NOT expose a covariate-driven NHPP learner.
  [VERIFIED: x-datainitiative.github.io/tick/modules/hawkes.html]
- Binned Poisson regression via `statsmodels.GLM(Poisson, log, exposure=...)` is
  the textbook primitive for NHPP fits with covariates. It gives us standard
  errors, deviance residuals, AIC, covariance matrix — all free.
- ROADMAP line "using `tick` 0.8.0.1 (FILL-01)" is reframed: `tick` stays in
  the stack for simulation (calibration Monte Carlo) and v1.0 Hawkes overlay
  staging. FILL-01's spirit (log-linear NHPP per market-side) is preserved;
  its letter (fit via tick) is amended with an orchestrator-surfaced note.
