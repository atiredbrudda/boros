<threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Git repo → disk | `.env.vault` (encrypted) is committed; `.env.keys` (plaintext private key) MUST NOT be. Pre-commit hook is the enforcement surface. |
| Login session → launchd headless | Keychain item must be accessible to launchd-spawned process (same UID, `-A` flag) without GUI prompt. |
| Process memory → log files | Agent key is decrypted by dotenvx into environment at startup, must never reach structlog JSON output. Redaction processor is the enforcement surface. |
| macOS sleep/wake → running bot | Keychain re-locks on sleep in some configurations; running processes retain their cached env so they're fine, but a crash-restart during a locked-keychain window would fail silently. Runbook documents this. |

## STRIDE Threat Register (ASVS L1)

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06-01 | Information Disclosure | Agent private key in staged git diff | mitigate | `scripts/no_plain_keys.py` pre-commit hook: greps staged files for `^0x[a-fA-F0-9]{64}$` and `-----BEGIN [A-Z ]*PRIVATE KEY-----`; exit 1 on match. Task 2 enables it in `.pre-commit-config.yaml`. |
| T-01-06-02 | Information Disclosure | Agent key leaked to structlog JSON line | mitigate | `python/src/boros_brain/logging/redaction.py` structlog processor: redacts any dict key matching `/^(api[-_]?key\|token\|secret\|private_key\|.*PRIVATE_KEY.*\|password)$/i` (case-insensitive) to `"***"` BEFORE `JSONRenderer`. Inserted by `configure_structlog(extra_processors=[redact_sensitive])`. |
| T-01-06-03 | Elevation of Privilege | Launchd plist executes arbitrary code from `~/Library/LaunchAgents/` | accept | LaunchAgent runs as the operator user (no privilege gain); install is documented one-time operator action in runbook. Not a network-exposed attack surface on a personal laptop. |
| T-01-06-04 | Denial of Service | Bot crashes in fork-storm after bad config | mitigate | Plist sets `ThrottleInterval=30` (min 30s between restarts per research §Pattern 7 gotcha 3) and `KeepAlive={SuccessfulExit=false}` so exit-78 (`EX_CONFIG`) breaks the restart loop. Runbook documents recovery. |

#!/usr/bin/env python3
"""Pre-commit hook: reject staged files containing plaintext private keys.
Rejects: 0x<64 hex>, BEGIN [X] PRIVATE KEY blocks.
Ignores: .env.vault (dotenvx ciphertext has high-entropy strings); tests/ directory when FAKE_KEY_FOR_TESTS sentinel is present on same or preceding line.
Exit 0 on clean, 1 on match.
"""
import re, subprocess, sys
from pathlib import Path

HEX_KEY = re.compile(r"\b0x[a-fA-F0-9]{64}\b")
PEM_KEY = re.compile(r"-----BEGIN [A-Z ]*PRIVATE KEY-----")

def staged_files() -> list[Path]:
    out = subprocess.check_output(["git", "diff", "--cached", "--name-only", "--diff-filter=ACMR"], text=True)
    return [Path(p) for p in out.splitlines() if p.strip()]

def scan(path: Path) -> list[tuple[int, str]]:
    if path.name == ".env.vault": return []
    if not path.exists() or not path.is_file(): return []
    try:
        lines = path.read_text().splitlines()
    except UnicodeDecodeError:
        return []
    hits = []
    for i, line in enumerate(lines, start=1):
        if HEX_KEY.search(line) or PEM_KEY.search(line):
            # Sentinel-based allowlist for test fixtures
            if "FAKE_KEY_FOR_TESTS" in line: continue
            prev = lines[i-2] if i >= 2 else ""
            if "FAKE_KEY_FOR_TESTS" in prev: continue
            hits.append((i, line))
    return hits

def main() -> int:
    fail = 0
    for p in staged_files():
        hits = scan(p)
        for lineno, line in hits:
            print(f"[no_plain_keys] {p}:{lineno}: {line[:80]}", file=sys.stderr)
            fail = 1
    return fail

if __name__ == "__main__":
    sys.exit(main())
```

"""structlog processor that redacts sensitive keys before JSON render.
Phase 1 / INFRA-12 / ASVS V7. Injected via configure_structlog(extra_processors=[redact_sensitive]).
"""
import re
from typing import Any

_SENSITIVE = re.compile(
    r"^(api[-_]?key|token|secret|private[-_]?key|password|.*DOTENV_PRIVATE_KEY.*)$",
    re.IGNORECASE,
)

def redact_sensitive(logger: Any, method_name: str, event_dict: dict) -> dict:
    """structlog processor signature. Replaces values of sensitive keys with '***'."""
    for k in list(event_dict.keys()):
        if _SENSITIVE.match(str(k)):
            event_dict[k] = "***"
    return event_dict
```
