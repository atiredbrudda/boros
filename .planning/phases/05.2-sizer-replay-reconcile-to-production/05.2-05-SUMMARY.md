# Phase 05.2 Plan 05: sigma_others from parquet + EmptyCompetitionPoolError

**One-liner:** Bug #3 fix — per-tick parquet read of sigma_others replaces silent bare-except sigma_others=0, raising EmptyCompetitionPoolError on empty pool.

---

## What was built

### Task 1: EmptyCompetitionPoolError + parquet helper + bug removal

**Commit:** `347b6f6`

- Created `python/src/boros_brain/backtest/exceptions.py` with `EmptyCompetitionPoolError(market_id, chain_ts, reason)`. Constructor stores all three attributes; `str(e)` includes all fields. Class docstring references Bug #3, the original bug location (`replay.py:489-500`), and the wiki page slug.

- Added `_read_sigma_others_from_parquet_at_ts(chain_ts, q_me_pendle) -> float` to `ReplayEngine`:
  - Lazy-loads `order_book_raw` parquet once per run (mirrors `_amm_raw_df` cache pattern)
  - Schema-normalises `sz_float`→`size` and `sz`→`size`; casts `snapshot_ts` from String to Int64
  - Filters to snapshot ≤ chain_ts; raises `EmptyCompetitionPoolError` on empty partition or no qualifying snapshot
  - Sums in-range sizes [clo_lower, clo_upper] from config.markets
  - Applies `sigma_others_min_pendle` floor AFTER guard, not as substitute

- Removed bare-except block at `relay.py:489-500` (the Bug #3 location). The silent `sigma_others = 0` path is gone.

- Wired the helper per-tick in `_build_evaluate_input` so sigma drift is captured across the replay window.

- Decision on `config.markets=[]` case: returns `sigma_others_min_pendle` with a warning log rather than raising. Rationale: empty config.markets is a configuration gap (not a data error), and existing tests with `default_config` (which has `markets=[]`) should not fail catastrophically on this path.
