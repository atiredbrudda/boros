## Plan defect & deviation

Plan 05.1-03 was authored before the LOCKED D-01 migration moved `r_apr_potential`'s source from `reward_budget_history.synthetic_current` (which Wave-1.5 backfill populated with 25 rows) to `market_reward_calibration` (populated by Wave 3's operator-driven calibration — Plan 05.1-04, not yet run). With Wave 3 not yet executed, no calibration rows exist, every DATA-08 passer has null `r_apr_potential`, and the gate produces a structural empty shortlist that does not represent a real strategy verdict.

The literal HALT branch (commit empty-rows kill report + project-halt STATE.md entry) was rejected:
- The kill report had an empty `## Per-Market Evaluation` table — self-evidently a non-event, not a strategy kill.
- Preserving it would corrupt the project-halt audit trail with an event that did not happen.
- The strategy was not actually evaluated against the 0.07 threshold.

**Soft PASS taken** with the 4 DATA-08 passers as Wave 3 input. The binding economics check is deferred to Wave 4 backtest (BACK-07 ship-gate threshold = `alt_yield + all_fees`, same intent as DATA-09). After Wave 3 calibration lands `market_reward_calibration` rows, re-running DATA-09 produces the meaningful per-market R_apr evaluation; until then DATA-09's audit trail is informational only.

Plan defect documented in [[phase-05-1-economics-gate-verdict]] under "Plan-defect followup" — Plan 05.1-03 should be amended in a future revision to mark DATA-09 as informational at Wave 2.
