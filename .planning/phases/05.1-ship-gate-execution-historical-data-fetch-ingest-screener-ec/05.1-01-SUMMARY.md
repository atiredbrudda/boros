## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing] scripts/__init__.py added**
- **Found during:** Task 4 (RED phase — ImportError on `from scripts.fetch_historical_data import ...`)
- **Issue:** `scripts/` directory had no `__init__.py`, making it non-importable as a Python package from pytest tests.
- **Fix:** Created empty `scripts/__init__.py` + added `".."` to `pythonpath` in `python/pyproject.toml`.
- **Files modified:** `scripts/__init__.py`, `python/pyproject.toml`
- **Commit:** `ebe197a`

**2. [Rule 1 - Bug] monkeypatch strategy changed from env vars to setattr**
- **Found during:** Task 4 (GREEN phase — SQLite row count = 0 despite patched env vars)
- **Issue:** `BotConfig` is `frozen=True` and loaded from YAML; `load_config` ignores env vars. `monkeypatch.setenv("BOROS_SQLITE_PATH", ...)` had no effect.
- **Fix:** Replaced env-var monkeypatching with `monkeypatch.setattr(fetcher_mod, "load_config", _make_patched_load_config(...))` using `model_copy(update=...)` on the frozen config.
- **Files modified:** `python/tests/test_fetch_historical_data_manifest_first.py`
- **Commit:** `ebe197a`

**3. [Rule 1 - Bug] MarketsPoller live refresh skipped**
- **Found during:** Task 3 (constructor requires http client + AsyncWeb3 + run_id — cannot invoke standalone)
- **Issue:** Plan's "Form A" invocation `asyncio.run(MarketsPoller(cfg).tick())` fails with `TypeError: __init__() missing 2 required positional arguments`.
- **Fix:** Applied plan's documented fallback — used UAT 29-market snapshot; documented in wiki page under "MarketsPoller Refresh Status".
- **Files modified:** `[[markets-pre-filter-2026-04-26]]` wiki page (fallback documented)
- **This was a documented fallback path in the plan, not an unexpected deviation.**
