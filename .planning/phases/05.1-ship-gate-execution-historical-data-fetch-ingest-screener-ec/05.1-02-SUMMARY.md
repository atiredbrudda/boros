# 05.1-02 Summary — Wave 1: Bulk Fetch + Bulk Ingest

## What was built

**`_run_fetch_loop` implemented** in `scripts/fetch_historical_data.py`: Branch A URL pattern (`files.json` master manifest + per-file static GET), `ThreadPoolExecutor(max_workers=6)`, 3-attempt linear backoff, ZIP extraction via `_safe_extract_zip`, idempotency via `_is_already_fetched`/`_record_fetched`.

**`build_market_id_mapping()`** resolves local `clo_history.market_id` (e.g. `HYPERLIQUID-BTC-29MAY2026`) to archive numeric-prefix IDs (e.g. `109-HYPERLIQUID-BTC-29MAY2026`) via `files.json`. Output: `var/fetcher/market_id_mapping.json`.

**`scripts/05_1_bulk_ingest.sh`**: `xargs -P 4` orchestrator over all `(kind, src, extra-args)` tuples from `data/ndjson/`. Dispatches `python -m boros_brain.data.ingester.cli` per job. Surfaces all errors — does NOT swallow `AMMConservationError`.

## Deviations

1. **Local DNS** — `socket.getaddrinfo` fails for `historical-data.boros.finance` in operator environment; resolved via `httpx` transport-level IP override.
2. **underlying-apr format** — archive uses `Binance-Eth` (title-case); alias table handles mapping.
3. **xyz-prefix markets** — `xyzGOLD` → `xyzGold` in archive; alias table handles.
4. **Settlement null market_id** — archive settlement NDJSON lacks `market_id` field; some records land under `__HIVE_DEFAULT_PARTITION__`. Non-blocking for screener (DATA-08 does not require settlement as primary input).
